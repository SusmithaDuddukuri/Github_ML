GETTING STARTED

Field guide

A short guide to interpreting this workspace responsibly.

Read a signal, not just a score.

Each alert in this preview is a seeded example. Its confidence value is illustrative and is not produced by a trained model. Severity indicates the sample triage category, not a verified real-world risk.

Explore the map

Use Signal explorer to filter by category and severity. Select a marker to inspect the record and use CSV export to share the sample dataset.

Respect data provenance

Before operational use, connect a documented imagery or environmental data provider, store source timestamps and lineage, and validate every model against a representative labeled dataset.

Access roles

Accounts are assigned analyst access by default. Admin access is bootstrapped through the configured email at registration. Never expose the bootstrap configuration or development secret in production.
